    Appendix

    What it searches

    Every caption collected from @cristiano's Instagram grid, 2,412 posts from March 2017 to October 2026. Emoji-only captions and collab posts by other accounts are hidden from search; they stay in the database.

    How results are ranked

    A small multilingual embedding model scores each caption by meaning. SQLite full-text search scores exact words. The two rankings are fused with Reciprocal Rank Fusion, with meaning weighted more than words. Both are precomputed, so the same query always gives the same order.

    Run it

    pip install -r requirements.txt, then python src/serve.py, then open http://127.0.0.1:8000. The first start loads the model for about a minute; the status chip says Warming up until it is ready. The server listens on your machine only.

    Sound

    SIUUU is synthesized in your browser from a noise burst, a gliding tone and a crowd swell. It is an imitation, not a recording. Sound is off by default and the toggle plays it after each new search.

    Limits

    The grid stopped loading at March 2017, so roughly 1,700 older posts are missing. Likes are as of capture time. Captions are Ronaldo's and his team's text, shared for research and fun.
